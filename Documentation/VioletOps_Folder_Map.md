# **VioletOps Folder Map**

## **Master Working Location**

The main VioletOps working folder is:

`C:\VioletOps\`

This is the source of truth for project files, documentation, scripts, screenshots, configuration exports, ISO files, backups, and VM-related materials.

## **ChatGPT VioletOps Project**

The ChatGPT VioletOps Project is used for:

* Project conversations  
* Step-by-step guidance  
* Troubleshooting  
* Architecture planning  
* Documentation drafting  
* Build verification

## **ChatGPT Library**

The VioletOps Library folders contain selected documents and screenshots that may be useful for reference inside ChatGPT.

The Library does not need to exactly match the folders on the homelab computer.

## **GitHub Repository**

The GitHub version of VioletOps will contain sanitized portfolio documentation.

Do not upload:

* Passwords  
* API keys  
* Private certificates  
* Sensitive configuration exports  
* Personal information  
* Screenshots containing private information

## **Folder Naming Rule**

Computer folders are organized by technology and file type.

ChatGPT Library folders are organized by documentation category.

The folder names do not need to be identical as long as this folder map explains where information belongs.
